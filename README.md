# The Dog Ate My Homework: Funniest Excuse

One original line of plain text: the excuse a dog gives, in its own voice, after being caught eating the homework. The dog admits to eating only the answers, points at the questions still lying on the floor as its alibi, and concludes the homework is half done — and that it is the only one in the house who did any work at all.

## The entry

> I only ate the answers — the questions are still on the floor, so the homework is half done, and I am the only one here who did any work at all.

## How it runs

`node main.ts` writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). The output is deterministic: every run produces the same bytes. The line is 144 characters, inside the gate's 1–200 character limit.
